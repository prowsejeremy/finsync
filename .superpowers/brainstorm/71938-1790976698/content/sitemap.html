Proposed breakdown: five sub-projects

We can still sketch every screen, but each group gets its own spec, plan and build cycle. Each one leaves the app in a working state.

1App shell + Settings

  • New navigation shell
  • Space for the mini-player
  • Settings takes over Sync status, Downloads, Albums to sync, Directory, Auto-sync, Server

No new features. The app still syncs exactly as it does today, just in a new place.

2Playback + Player

  • Background playback service
  • Lock screen and notification controls
  • Mini-player + full Player screen
  • Albums → Album detail first browse path

The thinnest slice that plays a real track from start to finish.

3Library browsing

  • Home
  • Artists → Artist's albums
  • Album Artists
  • Genres, Songs, Playlists
  • Audio Books

Reuses the list pattern and playback from #2.

4Search

  • One search across albums, artists, songs, playlists and books

Needs the browse destinations from #3 to link to.

5Equaliser

  • Presets + band sliders
  • Hooked into the playback service's audio output

Stands alone. It only needs the player from #2.
